# Changelog

## 1.2.0

- Timer Same as Cooldowns is now two options: Timer Number Same as Cooldowns and Timer Sweep Same as Cooldowns, so you can match just the number, just the sweep, or both.

## 1.1.0

- Timer Colour: pick your own colour for the timer's sweep and time (gold by default).
- Timer Same as Cooldowns: give the timer the game's normal cooldown look instead of a colour.
- Timer Sweep, Timer Time Left and Timer Stack Count: show or hide each part of the timer.
- Fixed an error in combat that could stop some buttons' timers from updating.

## 1.0.1

- No changes in game. Releases are now built and uploaded automatically.

## 1.0.0

- First release: your buff and debuff timers on your action buttons.
